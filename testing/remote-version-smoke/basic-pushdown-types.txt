# Types of the basic list: the operations that the connector pushes down to a remote
# server of any version. run.sh compares every operation on each type with the result
# of the local server, on each remote version that it runs.
#
# name | type | operations | values
#
# Every type gets <>, IS NULL, OR, count, count_if, count(DISTINCT), checksum, and
# GROUP BY. The operations column adds:
#   equal  =, IS [NOT] DISTINCT FROM, and NOT over them. A join on them makes the
#          remote server build a dynamic filter. Servers before 484 compare a list of
#          2 to 7 real values or values with a time zone by their raw form, and
#          servers before 482 fail to order arrays and rows with a null element.
#   filter the connector pushes down column filters on the type. run.sh compares one
#          column with a constant by =, <, and, with in, IN. The engine also derives
#          column filters from NOT over a comparison and from NOT IN with a constant.
#   const  comparisons with a constant inside an expression. The connector cannot
#          send uuid and ipaddress constants in an expression.
#   order  ordering comparisons, min, max, ORDER BY ... LIMIT, and, with join, a join
#          on an equality and an ordering comparison
#   in     IN with columns and with constants, which needs equal and const
#   sum    sum. The engine casts tinyint, smallint, and integer values to bigint for
#          sum and avg, and casts are not in the basic list.
#   avg    avg
#   join   an inner, a left, and a right equality join, which need equal
# The values are cast to the type. The table holds every pair of them, and of NULL.
# TestTrinoCompatibilityRegistry requires this list to match the basic list of
# TrinoCompatibilityRegistry.
